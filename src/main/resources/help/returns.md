# Returns

## Returning an item

Any item can be returned within 30 days of delivery, in its original packaging.
Start the return from the order page and the shop emails a prepaid return label.

## Refunds

The refund goes back to the original payment method within 5 working days of the return reaching the warehouse.

## What cannot be returned

Opened bags of coffee beans and used paper filters cannot be returned, for hygiene reasons.
