# Git

## Commits

Write the subject in the imperative, in at most 72 characters: `Reject a path outside the workspace`.
Say why in the body and not what, because the diff says what.
One commit does one thing, and the build passes at every commit.

## Branches

Work on a branch and never on main. Keep a branch short: merge it or drop it within a few days.
Rebase a branch on main before it is merged, so that the history stays a line.
